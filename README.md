# Tarang Go-To-Market Analytics Dashboard

## Overview
Developed a Power BI dashboard to identify high-potential furniture stores, prioritize sales opportunities, and support market expansion strategies.

## Tools Used
- Power BI
- SQL
- DAX
- Excel

## Key Features
- Area-wise Market Analysis
- High Priority Shop Identification
- Store Ranking System
- KPI Tracking
- Expansion Opportunity Analysis

## Business Impact
- Evaluated 296 stores
- Identified 220 high-priority stores
- Shortlisted 41 final target stores
- Enabled data-driven sales planning
